# AutoDrift Brand Images Guide
========================================

To replace the logo and icon on your website, simply place your image files in this folder (`public/images/`):

1. **Brand Icon / Emblem**:
   - File name: `icon.png` (or `.svg` / `.webp`)
   - Recommended dimensions: 512x512 px (Square, transparent background PNG recommended)
   - Used for: Top navigation icon, Admin sidebar icon, Mobile menu icon, and Login screen emblem.

2. **Brand Logo / Wordmark**:
   - File name: `logo.png` (or `.svg` / `.webp`)
   - Recommended dimensions: 400x100 px to 800x200 px (Horizontal/Landscape, transparent background PNG recommended)
   - Used for: Header brand banner and Admin navigation.

If you don't provide an image, the system automatically uses the sleek built-in glowing red badge and clean typography as a fallback!
